# roshambo
A basic rock paper scissors game.

Plan:
Allow a user to initiate a game.
Allow the user to choose the following: 1 round, 3 rounds, and or 7 rounds.
Allow them to choose an option out of the three moves.
Have a timer that goes 3 2 1 go!
Repeat if they chose more rounds.
After the game ends ask for a rematch which goes to the round choices again.
Or allow them to exit and end the program.

Future: Add a GUI to the game.
